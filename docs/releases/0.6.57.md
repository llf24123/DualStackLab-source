# 0.6.57

## 安装与文件安全

- 修复部分 APKS 无法安装：直接读取二进制 Manifest，支持不带资源表的 ABI 分包及资产分包，保留安装所需的资源包并检查版本一致性。
- 回收进程退出后遗留的安装缓存，保留仍在使用的安装和预览数据。
- 跨存储移动按已复制清单清理来源，保留复制期间新增或发生变化的文件；删除来源中断后可以继续完成清理。
- 覆盖前比较底层文件身份，避免不同 URI 指向同一文件时将来源截断。无法确认身份的移动覆盖要求另存一份。
- SAF 复制失败回滚只清理能够核实身份和内容的输出文件，保留 SAF 目录及无法核实归属的文件。

## 文件操作进度

- 复制、移动、解压进行时，在文件列表下方显示临时进度条，完成或失败后自动隐藏；短操作延迟显示，避免闪烁。
- 显示当前阶段、已处理大小、速度及预计剩余时间；总量可确定时显示百分比和总大小。
- 目录复用原有遍历统计，避免为计算进度重复扫描。未知总量、校验、归档重建及提交阶段使用不确定进度，避免提前显示完成。
- 支持停止操作，保留已完成项目；页面重建后重新关联进行中的操作。

## 归档、搜索与交互

- ZIP 列表、读取、替换、重命名及批量删除统一处理安全的相对路径，继续拒绝越界和规范化后的重复条目。
- APK 工具保存系统选择器待操作目标，返回后核对来源版本；工作副本随使用者和在途操作释放。
- 减少直接编辑压缩包内结构化资源时的重复读取。
- 普通关键词按块搜索，支持超长行和跨块匹配；跨行正则保持一致语义，正则限制明确显示跳过原因。
- 大选择集不再塞入 Activity 状态包；图片翻页沿用文件列表筛选；恢复默认首页同时恢复两个路径。
- 紧凑列表触摸高度至少 48dp，保留默认黑色文件夹图标与原横向间距。
- 外部传入的可执行文件增加运行确认。
- Shizuku 目录列表使用一次快照分页，控制每页数据量并修复顶层变更通知。

安装包仅在本地交付。源码使用通用安装标识，不包含私有签名和安装配置。
