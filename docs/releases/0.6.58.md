# 0.6.58

## 安装

- APKS 安装前在后台检测 ROOT 授权。已授权时跳过“允许安装未知来源”设置和系统安装确认，使用 Package Manager 静默安装用户选择的分包，并限定到当前 Android 用户。
- 分包路径经 Shell 安全引用，缺失或空文件会在执行安装前拒绝。ROOT 安装失败时展示系统错误，不会自动重复启动另一种安装流程。
- 未获得 ROOT 或设置中关闭 ROOT 时，继续使用原有 Android 系统安装器，并遵守未知来源授权。
- 单 APK 安装不再仅依赖先前缓存的 ROOT 状态；进入安装流程后在后台重新确认授权。
- Root 静默安装使用当前应用用户的用户 ID；分包命令、缺失分包和取消/超时均有明确处理。
